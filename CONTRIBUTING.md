# Contribuindo

Obrigado por ajudar a manter o MindFlow simples, privado e fácil de adaptar.

## Antes de abrir uma alteração

1. Preserve o modelo local-first: dados pessoais não devem depender de um servidor por padrão.
2. Não inclua backups, nomes reais, chaves ou arquivos `.env` no commit.
3. Mantenha a tela **Hoje** curta e orientada à próxima ação.
4. Rode `npm run check` antes de enviar mudanças em JavaScript.

## Escopo inicial

Prefira melhorias pequenas e verificáveis: acessibilidade, fluxo diário, backup, responsividade e documentação. Para integrações externas, documente claramente quais dados deixam o navegador e ofereça uma alternativa local quando ela fizer sentido.
